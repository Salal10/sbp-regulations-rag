# SBP regulations Q&A (work in progress)

Ask questions about State Bank of Pakistan rules on digital payments and customer protection, and get answers that cite the document and page they came from. If the documents don't cover the question, it should say so.

Documents used (public, from SBP's website):

- Regulations for Electronic Money Institutions, 2023
- Licensing and regulatory framework for digital banks, 2022
- Branchless Banking Regulations, 2019
- Rules for Payment System Operators and Payment Service Providers, 2014
- Consumer Grievances Handling Mechanism, 2016
- Payment Systems and Electronic Fund Transfers Act, 2007

The PDFs aren't stored in this repo. Download them with:

```
uv sync
uv run python -m sbp_regulations_rag.download
```

Not legal advice. Regulations get amended; these are the versions listed above.
